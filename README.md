# База данных линий — GitHub Pages

Готовый статический сайт на HTML + CSS + JavaScript.

## Файлы
- `index.html` — главная страница
- `style.css` — дизайн и адаптивная верстка
- `script.js` — мобильное меню

## GitHub Pages
1. Создайте новый GitHub repository.
2. Загрузите эти 3 файла в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Сохраните и дождитесь публикации.

Все ссылки на страницы `linedatabase.com` открываются в новой вкладке.
